## 🎯 Error Handling

When something fails:

1. **Read the actual error** clearly
2. **Identify the root cause** (not random attempts)
3. **Try safe, reasonable fixes** first
4. **Re-run the operation** and verify
5. **Explain the problem** with solution if blocked
6. **Never claim success** if operation failed
